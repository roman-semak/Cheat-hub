# Курс React JS — основи розробки (Sigma Software University)

**Джерело:** https://university.sigma.software/courses/react/
**Дата фіксації матеріалу:** 2026-08-11

## Загальна інформація

- **Формат:** онлайн, викладання українською мовою з англомовною термінологією
- **Тривалість:** 14 занять по 2 години, курс триває ~3 місяці
- **Цільова аудиторія:**
  - розробники з мінімальним досвідом програмування на JavaScript, але з міцною теоретичною базою
  - фахівці, що переходять з інших front-end фреймворків
  - ті, хто обирає основний інструмент для front-end розробки

## Вимоги до вступу

- знання HTML/CSS
- базове володіння JavaScript
- розуміння DOM
- базові знання Git (рекомендовано)

## Програма курсу (14 модулів)

1. **Вступ**
   Структура курсу, інструменти розробки (Git, GitHub, Node.js, Chrome DevTools), основи веб-розробки, підходи до побудови застосунків (SPA, MPA, PWA), огляд фреймворків, переваги React.

2. **Повторення основ JavaScript**
   Об'єкти, масиви, функції, асинхронний JavaScript, стандарти ES6+, практики якісного коду.

3. **DOM та BOM**
   Обробка подій, навігація по елементах, browser storage, браузерні API.

4. **Знайомство з React**
   Основні концепції, VirtualDOM, компонентна архітектура, інструменти розробки React.

5. **JSX та рендеринг**
   Синтаксис JSX, рендеринг елементів, обробка подій, списки, умовний рендеринг, refs, fragments, render props.

6. **Стан та властивості компонентів**
   Stateful/stateless компоненти, потік даних, PropTypes, анти-патерни.

7. **Життєвий цикл компонентів**

8. **Форми та валідація**
   Робота з формами, техніки валідації, пакети для управління формами.

9. **Маршрутизація в React**
   History API та реалізація React Router.

10. **Управління станом (Redux)**
    Варіанти управління станом, архітектура Redux, middleware (redux-thunk, redux-saga), структурування проєкту.

11. **Hooks API**
    Огляд доступних хуків, створення власних (custom) хуків, кращі практики, анти-патерни.

12. **Взаємодія з сервером**
    Fetch API, пакети для HTTP-запитів, автентифікація/авторизація.

13. **Стилізація в React**
    Інструменти стилізації та техніки анімації.

14. **Фінальне заняття**
    Фреймворки для тестування, React Native, React VR, поради щодо кар'єрного розвитку.

## Результати навчання

Після завершення курсу студенти вміють:
- створювати сучасні застосунки на React
- керувати станом застосунку
- інтегруватися з API, включно з автентифікацією/авторизацією
- працювати з формами
