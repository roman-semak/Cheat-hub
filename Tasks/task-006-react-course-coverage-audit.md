## 📌 Опис

Перевірити відповідність проєкту програмі курсу Sigma Software University "React JS — основи розробки" (програму зафіксовано у [Docs/react-course-sigma-software.md](../Docs/react-course-sigma-software.md), джерело: https://university.sigma.software/courses/react/).

Кожен з 14 модулів курсу має бути:
1. **Покритий у коді** — в проєкті має існувати конкретний, знаходжуваний приклад/реалізація теми (не просто "ми використовуємо React, отже все покрито").
2. **Задокументований** — з поясненням концепції достатньо детально, щоб код-читер зрозумів "чому" і "як", а не тільки "що".

Це аудит документації/покриття, а не обов'язково розробка нових фіч — частина модулів вже може бути неявно покрита самою платформою Next.js/React і потребує лише явного винесення в документацію з посиланнями на конкретні файли.

## 📋 План виконання

### Крок 1: Fundamentals (модулі 1–3)
- [ ] Модуль 1 — Вступ: інструменти розробки (Git, Node.js, DevTools), SPA/MPA/PWA підходи, огляд фреймворків, переваги React — задокументувати в Docs/ або CLAUDE.md
- [ ] Модуль 2 — Повторення основ JavaScript: об'єкти, масиви, функції, асинхронний JS, ES6+, якість коду — знайти/додати приклади в `src/lib` або `src/components`, задокументувати
- [ ] Модуль 3 — DOM та BOM: обробка подій, навігація по елементах, browser storage, browser API — перевірити використання (напр. `useReadTracking.ts`), задокументувати

### Крок 2: Core React (модулі 4–7)
- [ ] Модуль 4 — Знайомство з React: основні концепції, VirtualDOM, компонентна архітектура
- [ ] Модуль 5 — JSX та рендеринг: JSX синтаксис, списки, умовний рендеринг, refs, fragments, render props
- [ ] Модуль 6 — Стан та властивості компонентів: stateful/stateless, потік даних, анти-патерни
- [ ] Модуль 7 — Життєвий цикл компонентів

### Крок 3: State & Data (модулі 8–12)
- [ ] Модуль 8 — Форми та валідація
- [ ] Модуль 9 — Маршрутизація в React: перевірити відповідність Next.js App Router логіці History API/React Router
- [ ] Модуль 10 — Управління станом (Redux): якщо Redux не використовується — задокументувати чому і яка альтернатива застосована (напр. `userStore.ts`)
- [ ] Модуль 11 — Hooks API: вбудовані хуки, кастомні хуки (напр. `useReadTracking.ts`), кращі практики
- [ ] Модуль 12 — Взаємодія з сервером: Fetch API, HTTP-запити, автентифікація/авторизація (`src/lib/auth.ts`, `src/app/api/`)

### Крок 4: Ecosystem & Extras (модулі 13–14)
- [ ] Модуль 13 — Стилізація в React: інструменти стилізації (Tailwind, Liquid Glass), анімації
- [ ] Модуль 14 — Фінальне заняття: тестові фреймворки, обізнаність про React Native/VR, кар'єрні поради — за потреби додати короткий розділ
